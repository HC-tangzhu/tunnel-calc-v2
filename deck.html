成果七:AI 助手 — 从"会聊"到"会算"

对话即计算 · 无 API 密钥时自动降级为内置规则引擎(内网可用)

💬规范知识问答

基坑支护、土压力、稳定性、内支撑、盾构等 20+ 话题,含公式表格与规范出处

⚡直调计算函数

👀自动联动

问答结果自动切换到对应模块继续深算;为接入院统一大模型接口预留了标准链路

🔒 说明:当前 AI 对话采用外部 API 直连,仅用于功能验证,未接入任何院内工程数据;正式部署形态(云端 API / 院内代理 / 本地部署)取决于院里算力与保密口径,见后文请求事项。

PART 03 · 存在的问题与困难 ★ 重点

困难一:经费使用口径不明确

立项至今经费零支出 —— 不是不需要花,是不敢花、不会花
119.928万元
立项总经费 · 截至目前 0 元支出

❓两个核心疑问,恳请明确

  • ① 购买 AI 大模型 API(云服务订阅),能否在科研经费中列支?走哪个科目?
  • ② 本地部署大模型设备(服务器/GPU 等),能否购置?如何入账(资产/费用)?

现状:预算中可对应的仅有"出版/文献/信息传播/知识产权(含软件购置费)"8 万元与"其他费用"5 万元——AI 能力主要靠免费额度与个人碎片时间支撑,难以持续。

⚡为什么急

该口径直接决定智能体层技术路线:云端 API / 院内代理 / 本地部署 三选一,年底前必须定,否则影响考核目标中 AI 能力相关项。

🔒与保密的关联

若设计数据不得出域,则必须本地部署或院内代理——经费口径、算力政策、保密结论三件事实际是一件事,建议一次问齐。
